        Workspaces

        Standing workspaces

        Always on the bar, in this order. The first is home, whose apps open there and only theirs.

          Home's apps

          By the app's name, such as Mail or Google Chat, ignoring case, so tide's google-chat is Google Chat too. Set here, they start at login, each that's an app on this Mac; tide's programs and web addresses are tide's.

            Name patterns

            JavaScript regular expressions, tried in order against a new window's title: the first that matches names its workspace by its first capture.

              Shared with tide's workspaces.json. A change applies at once. The muted apps and sites are under Notifications.

              Floating

              Rules that float an app's windows, by its bundle ID and, if you like, a Lua pattern found anywhere in the title, such as ^Save. Escape a pattern's magic characters with %: %. is a dot. They come after start()'s rules, before tide's own, and dialogs float whatever they say. A new rule floats the windows open now that it covers, but not one you tiled by hand.

                More about this window

                Floating now

                Floating windows no rule covers, one per app. Always float fills in a rule for it to trim and add.

                  Appearance

                  Notifications

                  Apps and sites that are never marked for attention. Mute one with Cmd+M, or a right-click, on its row in the switcher's Windows or Attention tab, or type its bundle id, or site: and a host, below. macOS still shows their banners: turn those off in Notifications settings.

                    Clipboard

                    Keeps copies

                    The picker's history, on Super+C, shared with tide's clipboard.json. It's kept in memory, so it starts empty at each login. Turning it off keeps what's there until it's cleared.

                    Clocks

                      A label shows on the bar: any text, nothing for just the time, or abbr for the zone's abbreviation. Enter sets it. The bar shows local last, after these.

                      Idle

                      Start at login

                        tide runs these once a login, in order, as it starts, unless one's program is running already. Each is a program and its words, with no shell. A change takes effect at the next login.
